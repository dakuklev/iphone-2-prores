# iPhone 2 ProRes

Быстрая пакетная конвертация видео с iPhone (HLG / Dolby Vision) в ProRes 422 LT или H.265 для стоков.

- Mac на Apple Silicon (M1 и новее), macOS 14+. Intel не поддерживается.
- Скачайте последний архив в разделе **Releases**, распакуйте и перетащите приложение в «Программы».
- Дальше приложение само сообщит о новых версиях.
